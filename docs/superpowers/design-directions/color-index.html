Where does color live at rest?

Same screen, same content, same type. Only the color philosophy changes. All three keep the register ladder (ink band for live, accent reserved for peaks). Pick the one your eye wants to live in, or name the mix.

C1 · Sport ink at rest

The sport's color becomes working ink: index numerals, counts, kickoff stamps, the active tab tick. Every screen carries its sport at low dose. Color = wayfinding.

C2 · Brand plate

One new vermilion chrome accent, used confidently on the masthead rule, counts, indices, stamps. Sport colors appear only when something is live. Color = brand chrome. (The Monocle move.)

C3 · Toned paper

Color enters as material: the lead sits on sand, UP NEXT on sage, QUIET WRAP on blush. Full-bleed plates, no boxes, accents stay live-only. Color = paper stock.
