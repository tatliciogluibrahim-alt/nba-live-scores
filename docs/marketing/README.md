# Marketing artifacts

This directory holds the marketing assets for the launch, generated by
the marketing phase (`docs/LAUNCH_PROMPT.md`) on 2026-10-13, for the NFL
season.

## Files

| File | Content |
|---|---|
| `show-hn.md` | Show HN title, first comment and fallback description. |
| `twitter-thread.md` | 5-post X thread with screenshot slots. |
| `product-hunt.md` | Tagline, description, maker comment, 6 gallery captions. |
| `substack-essay.md` | "Why I built a sports app without a feed", about 1,250 words. |
| `reddit-r-nfl.md` | r/nfl post, with the sub's self-promotion caveats. Replaces the r/nba draft until the NBA Playoffs return in April. |
| `reddit-r-sideproject.md` | r/SideProject post. Replaces the r/soccer draft (the tournament ended July 19). |
| `threads-bluesky.md` | Single posts and 3-post threads for Threads and Bluesky. |
| `outreach-list.md` | Newsletters, bloggers and podcasts, each with a specific pitch angle. |
| `portfolio-case-study.md` | The case study for a portfolio, LinkedIn or dev.to. |
| `LAUNCH_DAY_CHECKLIST.md` | Gate, T-7 to T+7, hour by hour on the day. |
| `instagram-launch-prompt.md` | An earlier design brief for an Instagram set (System D era). |

Several posts say the iPhone lock screen never receives a hidden score.
That is true from v1.0.5. The lines are marked, and the checklist makes
v1.0.5 a launch gate.

## Related files

- `docs/LAUNCH_PLAN.md` — the strategy (why these channels, what we're
  measuring, what success looks like).
- `docs/LAUNCH_PROMPT.md` — the executable prompt that generates
  everything in this directory.
- `docs/SEO_SUBMISSION.md` — Google + Bing setup walkthrough.

## How to trigger generation

In a Claude Code session in the project root, say one of:

- "let's start the marketing phase"
- "let's do marketing"
- "start the launch"

Claude reads `docs/LAUNCH_PROMPT.md` and runs the five phases. Outputs
land in this directory.
