# Marketing artifacts

This directory holds the actual marketing assets for the launch. Files
here are **generated by running the marketing phase** (see
`docs/LAUNCH_PROMPT.md`).

Until the user triggers that, this directory is empty except for this
file.

## What gets generated

When the marketing phase runs, these files appear here:

| File | Content |
|---|---|
| `show-hn.md` | Hacker News Show HN post title + body + first comment. |
| `twitter-thread.md` | 5-tweet thread for the launch. |
| `product-hunt.md` | PH listing tagline, description, gallery captions, maker comment. |
| `substack-essay.md` | 1,200 to 1,500 word essay for Substack/Medium/dev.to. |
| `reddit-r-nba.md` | r/nba post (title + body) timed for NBA Finals. |
| `reddit-r-soccer.md` | r/soccer post timed for WC kickoff. |
| `threads-bluesky.md` | Threads + Bluesky variants of the launch posts. |
| `outreach-list.md` | 18 cold-pitch targets (10 newsletters + 5 blogs + 3 podcasts) with personalized angles. |
| `portfolio-case-study.md` | Canonical case study for the portfolio + LinkedIn + dev.to. |
| `LAUNCH_DAY_CHECKLIST.md` | Hour-by-hour launch day plan. |

## Related files

- `docs/LAUNCH_PLAN.md` — the strategy (why these channels, what we're
  measuring, what success looks like).
- `docs/LAUNCH_PROMPT.md` — the executable prompt that generates
  everything in this directory.
- `docs/SEO_SUBMISSION.md` — Google + Bing setup walkthrough.

## How to trigger generation

In a Claude Code session in the project root, say one of:

- "let's start the marketing phase"
- "let's do marketing"
- "start the launch"

Claude reads `docs/LAUNCH_PROMPT.md` and runs the five phases. Outputs
land in this directory.
